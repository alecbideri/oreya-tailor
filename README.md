# Oreya Tailor

Landing page for **Oreya Tailor** — tailoring for schools, events & organizations (school uniforms, event t-shirts, organization apparel).

## Overview

A premium, editorial-styled landing page built with **plain HTML/CSS/JS** (no framework). It follows the layout of a craft-forward reference site but pivots the message to large-scale project tailoring, with a warm orange brand palette.

## Features

- Sticky top nav with mobile hamburger menu (toggles to a close icon)
- Hero with a clear value proposition for bulk tailoring
- Numbered "Why Choose Us" value props
- Services grid with image placeholders (school uniforms, event t-shirts, organization apparel, bespoke/custom)
- About section with the two team members and their contact numbers
- Contact modal with a "copy number" action for the Commercial Director + an email form to `info@oreyatailor.com`
- Premium footer with a large serif "Oreya Tailor" wordmark and contact info
